# 在线 Playground

编辑代码后点击运行，实时观察状态机变化。基于 WebContainer，支持完整的 TypeScript + 装饰器。

:::note[浏览器支持]
WebContainer 仅在 Chrome / Edge 中可用。Firefox / Safari 用户可点击「在 StackBlitz 中打开」。
:::
